🔑 پیکربندی API گوگل (Google Gemini API)

برای استفاده از ترجمه هوشمند، کلید API خود را وارد کنید. کلید به صورت امن در مرورگر ذخیره می‌شود.

در صورت عدم استفاده از فیلترشکن، می‌توانید آدرس Cloudflare Worker یا پرکسی اختصاصی خود را وارد کنید.

🤖 انتخاب مدل هوش مصنوعی Gemini

مدل مورد نظر خود را برای پردازش ترجمه‌ها انتخاب کنید. می‌توانید لیست را آنلاین بروزرسانی کنید.

⚙️ تنظیمات پیش‌فرض اکستنشن

🛡️ راهنمای ساخت Cloudflare Worker رایگان جهت دور زدن تحریم

اگر نمی‌خواهید از فیلترشکن استفاده کنید، می‌توانید اسکریپت ساده زیر را در Cloudflare Workers (رایگان) قرار دهید و آدرس آن را در فیلد پرکسی بالا وارد کنید:

export default {
  async fetch(request) {
    const url = new URL(request.url);
    url.hostname = 'generativelanguage.googleapis.com';
    const modifiedRequest = new Request(url.toString(), {
      method: request.method,
      headers: request.headers,
      body: request.body
    });
    return fetch(modifiedRequest);
  }
};
